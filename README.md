# Unofficial DeepL Android App

## How it works

This app is an unofficial Android client for [DeepL](https://www.deepl.com).

Instead of being a completely native app built from scratch, this app works as a "Web Viewer". This means that when you open the app, it essentially opens a specialized web browser built right into the app that directly loads the mobile version of the DeepL translation website. It wraps the website to make it look and feel more like a dedicated app on your phone.

## Does it work offline?

**No, this app will not work offline.**

Because the app works by loading the DeepL website, it fundamentally requires an active internet connection to function. It sends your text to DeepL's servers to be translated and then receives the translated text back. Without an internet connection (Wi-Fi or mobile data), the app cannot reach the DeepL servers to perform translations.

## What is needed to use it?

To use this app, you simply need:

1.  **An Android Device:** A smartphone or tablet running Android (minimum version 5.0 / Lollipop / API level 21 or higher).
2.  **An Active Internet Connection:** You must be connected to Wi-Fi or have a mobile data connection for the app to translate text.
